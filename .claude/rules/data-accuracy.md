## 数据准确性规则

### 核心原则
LLM 在本系统中是"推理引擎 + 表达引擎"，不是"数据源"。

### 五层防线

1. **System Prompt 硬约束**
   - 明确告知 LLM 没有任何财务数据记忆
   - 所有数据必须通过工具查询

2. **Tool 返回结构化数据 + 来源标记**
   - 每个 Tool 返回：data + source + query_time + is_empty
   - 空结果明确标记 is_empty=true

3. **data_ref 结构化引用校验**
   - LLM 输出 display + data_ref
   - Tool Dispatcher 对 data_ref 做 JSON 级数值比对
   - 精确匹配 + 允许四舍五入误差 ≤ 0.5%

4. **派生值计算校验**
   - 增长率、占比等派生值校验计算公式
   - 不一致时用正确计算结果替换

5. **无数据兜底**
   - 查询无结果 → "没有找到相关记录"
   - 工具失败 → "查询暂时出了问题"
   - 数据不足 → "数据不足以进行分析"
