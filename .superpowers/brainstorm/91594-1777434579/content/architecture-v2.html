流式输出

关键数据流

1. 页面数据加载（HTTP）
Client → Auth Middleware → HTTP Router → Biz Service → Mock BizData → MySQL
用户切换页面 → 加载账单/预算/资产等数据 → 右栏渲染
2. AI 对话（WebSocket）
Client → Auth Middleware → Connection Mgr → AI Engine → 意图识别 → Skill → Tool → 流式返回
对话请求携带 page_context，AI Engine 据此加载对应 Skill 集
3. AI 触发写操作
AI Engine → 生成建议 → Client 确认 → Op Logger(快照) → Biz Service(复用) → Memory Mgr(更新记忆)
AI 写操作复用 Biz Service，不绕过业务层，保证数据一致性
4. 统计分析查询
AI Engine / HTTP Router → Analytics Engine → Redis 缓存(命中返回) → 未命中实时计算 → 结构化数据 → 图表渲染
页面报表和 AI 对话共用同一套 Analytics Engine
5. 记忆检索
AI Engine → Memory Mgr → L4 对话历史(Redis) → L1~L3 长期记忆(MySQL + Milvus 语义检索)
每次对话前自动检索相关记忆，注入 LLM 上下文，严格按 user_id 隔离
6. 主动推送
定时任务 → Analytics(预警检测) → Memory Mgr(判断推送) → Connection Mgr → WebSocket 推送
HTTP 降级模式下改为客户端轮询获取推送消息
