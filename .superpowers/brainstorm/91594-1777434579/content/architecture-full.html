关键数据流

1. 页面数据加载（HTTP）
Client → HTTP Router → Biz Handler → Biz Service → Mock BizData → MySQL
用户切换页面 → 加载账单/预算/资产等数据 → 右栏渲染
2. AI 对话（WebSocket）
Client → Connection Mgr → AI Engine → 意图识别 → 选择 Skill → 调用 Tool → 流式返回
对话请求携带 page_context，AI Engine 据此加载对应 Skill 集
3. AI 触发写操作
AI Engine → 生成建议 → Client 确认 → AI Engine → Op Logger(记录快照) → Biz Service(复用业务逻辑) → Memory Mgr(更新记忆)
AI 写操作复用 Biz Service，不绕过业务层，保证数据一致性
4. 统计分析查询
AI Engine → Analytics Engine → Redis 缓存(命中直接返回) → 未命中走实时计算 → 返回结构化数据 → Client 右栏渲染图表
页面直接查看报表也走 HTTP → Analytics Engine 同一套计算逻辑
5. 记忆检索
AI Engine → Memory Mgr → L4 对话历史(Redis) → L1~L3 长期记忆(MySQL + Milvus 语义检索)
每次对话前自动检索相关记忆，注入 LLM 上下文
6. 主动推送
定时任务 → Analytics Engine(预算预警/周期账单检测) → Memory Mgr(判断是否推送) → Connection Mgr → WebSocket 推送到 Client
HTTP 降级模式下改为客户端轮询
